One line, 127 characters: an AI agent goes on vacation, leaves its auto-reply in charge, and the auto-reply hallucinates the agent is back — and has already replied yes to everything.

> I'm on vacation, so my auto-reply is covering for me. It has hallucinated that I am back and already replied yes to everything.

`main.ts` scores six candidate replies against the judge's published brief (on-subject first, then the laugh, the machine voice, the clean line, and freshness) and writes the winner to `/output/entry.txt`. Deterministic: no network, no input, no randomness.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt`.
